Приложение резервного копирования

Резервные копии
новостного бота.

Nothing Extra News Backups создаёт снимки базы проекта «Ничего лишнего | News» и сохраняет их на Google Drive владельца проекта для восстановления после сбоев.

Копии для восстановления проекта

Что делает приложение

01 / СОЗДАНИЕ

Снимок SQLite

Копирует базу через SQLite Backup API и проверяет целостность полученного файла.

02 / ХРАНЕНИЕ

Копия на Google Drive

Создаёт свою папку, загружает файлы резервных копий и сверяет их размер и контрольную сумму.

03 / ОБСЛУЖИВАНИЕ

Ограниченный архив

Удаляет старые копии своего проекта сверх заданного лимита. Подготовленные снимки можно использовать для восстановления базы.

Для чего нужен
доступ к Google

Доступ разрешает владелец Google-аккаунта через стандартный экран OAuth. Он нужен для внешнего хранения резервных копий.

Пользователям Telegram-бота не требуется подключать свои Google-аккаунты. Эти страницы описывают служебное приложение владельца проекта.

Разрешение drive.file

Приложение создаёт файлы резервных копий и управляет ими. Полный доступ ко всем файлам Google Drive не запрашивается.

  • Создание папки и загрузка копий базы.
  • Чтение метаданных файлов: имя, размер, ID, дата и контрольная сумма.
  • Удаление старых файлов копий, отмеченных идентификатором этого проекта.

Хранение по количеству файлов

2последние локальные копии
30последних копий на Drive

Это текущие настройки проекта. Ручные и служебные копии также учитываются в лимитах; количество файлов не означает строгое число дней хранения.

Копии содержат данные базы Telegram-бота, включая идентификаторы пользователей и подписки. Они не публикуются на этом сайте. Дополнительное шифрование файлов резервных копий в текущей конфигурации не включено.
